## Guatemala / Endpoints / Certificación de documentos
En Felplex existe la posiblidad de poder enviar las peticiones de certificacion de la siguiente manera


Json: con parametros especificos para el DTE, revisar campos en Variables Generales



XML: Debe ser enviado en base 64




La certificacion de los documentos son de manera sincrona ya que espera la respuesta de la certificación


Autorización



Serie



Número de documento

## Guatemala / Endpoints / Envio de documentos
Los documentos en FELplex tienen la posibilidad de además de ser enviados a los clientes por medio de correo electrónico, utilizar la opción de envio por medio de:


SMS 📨: se un enviara el enlace con el cual pueden acceder al documento



Whatsapp 📱: Se enviara el documento en PDF, asi como el total y tipo de documento




Para esta opcion es necesario que el cliente posea creditos del tipo de medio de envio a utilizar

------------------------------------------------------------------------------------------

## Guatemala / Endpoints / Anulacion de documentos
La API de FELplex permite la anulacion de documentos, tomando en cuenta que la fecha de vencimiento del período del IVA al que corresponde el documento a anular, siendo este el tiempo restante del mes en el cual se emitió el documento y el siguiente.

------------------------------------------------------------------------------------------
### Guatemala / Endpoints / Anulacion de documentos / Anular DTE
DELETE {{entorno}}/api/entity/{{empresa}}/invoices/{{dte_uuid}}
HEADERS: [('Accept', 'application/json'), ('X-Authorization', '{{api_key}}')]
DESC: El UUID a ingresar debe ser el devuelto por parte de FELplex, no confundir con Autorizacion de SAT
BODY:
{



"reason":"Devolución"



}


EXAMPLE RESPONSE ( None ):
{

    "success": true, /*True, si la anulación fue exitosa, false si fallo*/

    "uuid": "10FC365A-72D7-4B4D-AAB8-CF847B5DA4C8", /*Uuid del documento anulado*/

    "certifier": { /*Datos del certificador*/

        "name": "CARI LATINOAMERICA, S.A.",

        "tax_code": "96941243"

    },

    "errors": [] /*En caso de haber fallado el proceso de anulacion se brindaran detalles del error*/

}

## Guatemala / Endpoints / Solicitud de datos
La API de FELplex permite solicitar algunos datos como lo son:


Solicitar datos de DTE: Permite consultar los datos de certificacion de un documento



Texto de DTE: Permite consultar los detalles completos de un documento electrónico previamente certificado



Listado de frases:


Exento del ISR: Frases que deben incluirse cuando el emisor se encuentra exento del Impuesto Sobre la Renta (ISR).



Exento de IVA: Existen facturas que por diferentes motivos deben llevar esta frase ya que:


NO deben incluir el IVA.



Deben incluir la base legal por la cual no incluyen el IVA (art. 29 literal “a” Ley del IVA y art. 11 Reglamento de la Ley del IVA).



Son recibos y recibos por donación la correspondiente base legal de exención de IVA.









Cantidad de DTE: Cantidad disponible de Documentos tributarios electrónicos de una empresa para su emisión
